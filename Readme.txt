================================================================
  1. 系統簡介
================================================================

本系統是一套本機學習管理工具，支援多人使用（家庭 / 師生），
可管理：課表、作業、考試倒數、讀書進度、讀書時間、成績，
並附有徽章獎勵與點數商店，讓學習更有動力。

‧ 不需網路，在家即可使用
‧ 區域網路內其他裝置（手機、平板）可同時連線
‧ 各帳號資料完全獨立，互不干擾
‧ 支援正體中文 / English / 日本語 切換


================================================================
  2. 啟動方式
================================================================

【推薦】雙擊「啟動.bat」
  ‧ 會自動開啟瀏覽器並進入系統首頁
  ‧ 每次使用前執行一次即可

【手動】開啟命令提示字元，進入系統資料夾後輸入：
  npm start

啟動後瀏覽器前往：http://localhost:3000

注意：使用期間請保持「啟動.bat」的視窗開著，關閉視窗即停止伺服器。


================================================================
  3. 切換帳號與語系
================================================================

【選擇帳號】
  ‧ 首頁顯示所有帳號卡片，點選即可進入
  ‧ 按「✏️ 編輯帳號」可刪除帳號，或點「+ 新增使用者」建立新帳號

【切換語系】
  ‧ 進入系統後，側邊欄最底部有「中 EN 日」三個按鈕
  ‧ 點擊即時切換，不需重新整理頁面
  ‧ 語系設定跟著帳號走，下次登入自動還原

【切換主題】
  ‧ 首頁右上角「🌙」按鈕可切換亮色 / 暗色模式


================================================================
  4. 功能說明
================================================================

------------------------------------------------------------
4-1  今日概覽（首頁進入後的預設頁面）
------------------------------------------------------------
提供當天所有學習事項的一覽表：

‧ 今日 / 明日課表：顯示當天與隔天的課程節次
‧ 今日作業：當日的作業清單，可直接勾選完成
‧ 今日 / 明日讀書進度：排定今明兩天的預習 / 複習項目
  → 點擊圓圈按鈕標記完成，會彈出「記錄時間」視窗（可略過）
‧ 待完成讀書進度：已過期尚未完成的進度（橘色警示）
‧ 考試倒數：最近 5 筆考試，顯示距今天數與讀書進度條


------------------------------------------------------------
4-2  每週課表
------------------------------------------------------------
排定每週固定的課程時間表。

‧ 頂部下拉選單選擇學年度與學期（上/下學期）
  → 中文介面顯示民國年（民國 114–120 學年度）
  → 英文 / 日文介面顯示西元年（2026–2032）
‧ 點空格子新增課程，點已有課程可編輯或刪除
‧ 不同學期的課表各自獨立

使用建議：先在「課程資訊」建立科目，再來排課表。


------------------------------------------------------------
4-3  行事曆
------------------------------------------------------------
月曆視圖，一次看清所有事件。

‧ 自動顯示：作業截止日、考試日期、讀書進度排定日
‧ 格子內有顏色標籤，hover 可看完整名稱
‧ 點日期格可查看當天詳情，或新增作業


------------------------------------------------------------
4-4  考試倒數
------------------------------------------------------------
追蹤所有考試，依狀態分三區：

‧ 即將到來：今天或未來的考試，顯示剩餘天數
  → 🔴 3 天內（緊急）　🟡 7 天內　🟢 7 天以上
‧ 已過期：日期已過但未標記完成，紅色左邊框提示
‧ 已完成：手動標記完成的考試

每筆考試下方顯示該科目的預習 / 複習進度條（藍 / 綠）。
「清除已過期」按鈕可一次將所有過期考試標為完成。


------------------------------------------------------------
4-5  作業清單
------------------------------------------------------------
管理每日的作業事項（自由格式，支援多部份完成）。

【新增作業】
  ‧ 可選科目、輸入作業名稱、選日期
  ‧ 可設定「分成幾部份完成」（1–10），例如：
    - 數學習作分 3 部份 → 勾完 3 個子框才算完成

【完成狀態】
  ‧ 單部份：圓形勾選框
  ‧ 多部份：顯示「N / 總數」進度，各部份有子勾選框
  ‧ 完成整筆作業時，自動觸發作業類徽章檢查

【分區顯示】
  ‧ 今日作業 / 未完成（逾期，紅色） / 即將到來


------------------------------------------------------------
4-6  讀書進度
------------------------------------------------------------
管理每個章節的預習與複習進度。

‧ 依科目分組顯示，點科目標題展開 / 收起
‧ 每章節有「預習」（1 次）+ 「複習」（可多次）進度
  → 點「+ 新增複習」增加一次複習記錄
‧ 每筆進度可設定：排定日期（連動行事曆）、備註
‧ 點按鈕標記完成：
  → 實心填色 = 已完成
  → 空心虛線 = 未完成
  → 標記完成時彈出「記錄時間」視窗（可略過）
‧ 章節旁顯示累積讀書時間

使用建議：先在「課程資訊」建立科目與章節，再來設定進度。


------------------------------------------------------------
4-7  讀書時間
------------------------------------------------------------
記錄每次讀書時間，自動產生圖表。

【手動記錄】
  ‧ 選科目、章節（選填）、日期、輸入分鐘數

【碼錶計時】
  ‧ 按「開始」→ 讀完後按「停止」→ 選科目後儲存
  ‧ 切換到其他頁面再回來，碼錶仍繼續計時

‧ 近 7 天讀書時間堆疊柱狀圖（各科目不同顏色）
‧ 記錄列表可刪除單筆紀錄


------------------------------------------------------------
4-8  成績紀錄
------------------------------------------------------------
追蹤各科目的考試成績與趨勢。

‧ 折線圖顯示成績趨勢，可依科目篩選
‧ 表格欄位：日期、科目、考試名稱、得分 / 滿分、班排名
  → 班排名可直接在表格點擊輸入（如「3」或「3/40」）
‧ 新增成績時可從「考試倒數」選取已建立的考試，
  自動帶入名稱、日期、科目


------------------------------------------------------------
4-9  我的徽章
------------------------------------------------------------
自動解鎖的系統徽章 + 自訂成就，完成任務即可獲得。

【系統徽章】（共 20 枚，四大類）
  ‧ 習慣類：連續記錄讀書 3 / 7 天等
  ‧ 努力類：累積讀書 10 / 50 / 100 小時等
  ‧ 完成類：完成作業、章節預習 / 複習等
  ‧ 成績類：首次登記成績、成績進步等
  ‧ 作業類：連續完成作業 1 / 3 / 7 天、累積 10 天

【自訂成就】
  ‧ 自行設定目標（名稱、圖示、說明、點數、分類）
  ‧ 完成後點「完成！」→ 再點「換 N 點」兌換點數

【徽章換點】
  ‧ 已解鎖的系統徽章可點「換 N 點」換取點數
  ‧ 每種徽章每天只能兌換一次

‧ 解鎖新徽章時，右下角自動彈出通知
‧ 頁面底部顯示所有兌換歷史紀錄


------------------------------------------------------------
4-10 獎勵商店
------------------------------------------------------------
用獲得的點數兌換自訂獎勵。

【許願池】
  ‧ 新增自訂獎勵（名稱 + 所需點數），例如：電影之夜 = 80 點
  ‧ 可刪除不需要的項目

【櫃台】
  ‧ 顯示目前點數餘額
  ‧ 點數足夠時按「兌換」即可扣點並記錄
  ‧ 點數不足時按鈕灰化，無法兌換

【兌換紀錄】
  ‧ 顯示歷史兌換記錄（名稱、日期、扣點）


------------------------------------------------------------
4-11 課程資訊
------------------------------------------------------------
管理科目與章節，是使用其他功能的前置步驟。

【科目管理】
  ‧ 新增科目時選擇代表顏色（24 色色票）
  ‧ 可修改名稱 / 顏色，或刪除科目（連帶刪除所有章節）

【章節管理】
  ‧ 點選左欄科目，右欄顯示該科目的章節清單
  ‧ 可新增、改名、刪除、調整上下順序


------------------------------------------------------------
4-12 列印週計畫
------------------------------------------------------------
產生可列印的 A4 橫式學習週計畫。

‧ 內含：近期考試倒數、本週讀書計畫
‧ 按 Ctrl+P 或瀏覽器列印按鈕直接輸出
‧ 支援儲存為 PDF


================================================================
  5. 備份與還原
================================================================

【備份】
  ‧ 首頁點「💾 備份資料」→ 瀏覽器自動下載備份檔
  ‧ 建議定期備份，存到雲端或隨身碟

【還原】
  ‧ 首頁點「📂 匯入備份」→ 選取 .db 備份檔
  ‧ 確認警告後自動還原，不需重啟伺服器
  ‧ 注意：還原後會覆蓋現有所有資料


================================================================
  6. 區網連線（其他裝置）
================================================================

讓家中手機 / 平板 / 其他電腦也能使用：

1. 確認主電腦已執行「啟動.bat」
2. 在主電腦上開啟命令提示字元，輸入 ipconfig
   找到「Wi-Fi」或「乙太網路」下的 IPv4 位址
   例：192.168.1.50

3. 其他裝置在同一 Wi-Fi 下開啟瀏覽器，前往：
   http://192.168.1.50:3000

若無法連線，請至「Windows Defender 防火牆」→「進階設定」
→「輸入規則」→「新增規則」，允許 TCP 連接埠 3000。


================================================================
  7. 常見問題
================================================================

Q：網頁開不了 / 顯示「無法連線」？
A：確認「啟動.bat」的視窗是否還開著。
   重新雙擊「啟動.bat」再試一次。

Q：點數不見了？
A：點數餘額 = 所有獲得點數 − 所有兌換扣除點數，
   不受兌換紀錄刪除影響。可在「獎勵商店 → 櫃台」確認餘額。

Q：課表顯示的學年度年份看起來不對？
A：系統依語系顯示：
   ‧ 中文 → 民國年（民國 114–120 學年度）
   ‧ 英文 / 日文 → 西元年（2026–2032）
   兩者代表相同學年，只是表示方式不同。

Q：徽章解鎖後怎麼換點數？
A：前往「我的徽章」，已解鎖但尚未兌換的徽章會顯示橘色
   「換 N 點」按鈕，點擊即可換點。每種徽章每天只能換一次。

Q：忘記存資料了，怎麼辦？
A：所有操作（新增、勾選、修改）都是即時儲存到資料庫，
   不需要手動存檔。

Q：想測試功能，會不會影響其他人的資料？
A：請使用「測試用帳號」進行測試，避免污染正式帳號資料。
