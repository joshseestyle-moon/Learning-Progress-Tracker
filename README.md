# 學習管理系統

> 版本：3.9　　本機局域網路多人學習管理工具，無需上雲、無需登入帳號。

## 功能

| 頁面 | 功能 |
|---|---|
| 個人選擇 | Netflix 卡片風格，點選進入 |
| 今日概覽 | 今日/明日課表、讀書進度、待完成逾期進度提醒、考試倒數；今日/本週讀書時間對照目標、連續天數、作業截止提醒、考前章節配速、等級卡與週回顧 |
| 每週課表 | 視覺化時間格，支援個人/共用課程 |
| 行事曆 | 月曆整合作業清單、考試與章節預習/複習事件 |
| 考試倒數 | 倒數天數卡片，標記完成，可依學習區間過濾 |
| 作業清單 | 每日作業，可分多部份完成，逾期/即將到期分組，可依學習區間過濾 |
| 讀書進度 | 各科目章節打勾進度條，支援多次複習排程；完成後依間隔重複（1/3/7/16/35 天）自動排定下次複習；可依學習區間過濾 |
| 讀書時間 | 碼錶計時 + 手動記錄 + 週統計圖 + 全年學習熱力圖 + 月度趨勢 + 累計總覽；可設定每日/每週讀書目標；可依學習區間過濾 |
| 目標設定 | 章節/成績/自由文字目標，短中長期，可綁定學習區間；並管理學期/寒暑假區間 |
| 成長軌跡 | 等級卡、飛輪四節點活躍度、累積成長折線、週 XP 長條、區間對比 |
| 學習歷程報告 | A4 可列印的學習總覽（總覽/科目/成績/目標/徽章/月趨勢/等級），可自訂日期範圍 |
| 成績紀錄 | 歷次成績表格 + 趨勢折線圖 |
| 我的徽章 | 成就徽章系統：習慣、努力、完成、成績四類，共 20 枚（含 4 枚作業類） |
| 獎勵商店 | 許願池、點數兌換、兌換紀錄 |
| 語系切換 | 正體中文 / English / 日本語，即時切換，依帳號儲存 |

### 遊戲化（飛輪）

以「鼓勵、不懲罰」為原則的成長系統：讀書/完成章節/完成作業獲得永久 **XP** 與**等級**（最高 50 級、10 段稱號）；達成每日目標累積 **combo**（每天 +10% XP，最高 ×2.0）；每日一次隨機**驚喜點數**；逾期項目可接**補救任務**（達標給獎、逾期不罰）。XP（成長）與點數（可花費於獎勵商店）為兩套獨立系統。

## 快速開始

### 1. 安裝 Node.js
從 https://nodejs.org 下載安裝（v18 以上）

### 2. 安裝依賴
```
cd X:\class
npm install
```

### 3. 啟動
```
npm start
```
開瀏覽器前往 http://localhost:3000

### 開發模式（儲存時自動重啟）
```
node --watch server.js
```

## 讓區網其他裝置連線

1. 在此電腦執行 `ipconfig`，找到 IPv4 位址（例：`192.168.1.50`）
2. 其他裝置瀏覽器開啟 `http://192.168.1.50:3000`
3. 若無法連線，新增 Windows 防火牆規則：
   - Windows Defender 防火牆 → 進階設定 → 輸入規則 → 新增規則
   - 類型：連接埠 → TCP → 特定本機連接埠：`3000` → 允許連線
   - 命名：`Study App`

## 資料庫

資料存在 `data/app.db`（SQLite 單一檔案）。
- **備份**：複製此檔案即可
- **重置**：刪除 `data/app.db`，重啟伺服器自動建立新資料庫

## 離線使用 Chart.js / Alpine.js

目前從 CDN 載入圖表庫。若需完全離線，請下載以下檔案：
- https://cdn.jsdelivr.net/npm/chart.js@4/dist/chart.umd.min.js → 存至 `public/vendor/chart.min.js`
- https://cdn.jsdelivr.net/npm/alpinejs@3.x.x/dist/cdn.min.js → 存至 `public/vendor/alpine.min.js`

然後修改 `public/app.html` 中的 script src 為 `vendor/chart.min.js`。

## 新增第一個使用者

1. 開啟 http://localhost:3000
2. 點選「+ 新增使用者」
3. 輸入姓名，勾選「設為管理員」（第一個使用者建議設為管理員）
4. 點選「新增」，再點選頭像進入系統
